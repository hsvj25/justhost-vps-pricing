## “不限流量”和“300Mbps”到底承诺了什么

JustHost 每一档的端口后面都跟着 `fair-share` 这个词，后面还有一行小字把端口速率换算成月流量：10Mbps 约等于 4TB+/月，300Mbps 约 93TB+/月，750Mbps 约 232TB+/月。

也就是说，**不限的是流量总量，不是带宽**。那个 TB 数字是端口 24 小时跑满一个月的理论上限，不是你能稳定拿到的速率。端口是共享的，实际能跑多少取决于同一台宿主机上其他用户当时的用量。个人博客一个月几十 GB，10Mbps 的 Promo 都用不满；真正会撞上天花板的是持续大流量场景，比如整站备份、视频中转、24 小时不间断的同步任务。

按这个逻辑，选套餐时先看内存和硬盘够不够，再看端口。为了 750Mbps 而不是 300Mbps 多付一倍价钱，对建站用户基本没有回报，因为你的瓶颈在访客数量和程序本身，不在那 450Mbps。

另外两个藏在配置器里的差异：

**硬盘类型直接改价格。** 同样是 1 核 512MB / 5GB，HDD 版 $3.25/月（年付 $2.60），SSD 版 $3.90/月（年付 $3.12），NVMe 版 $4.22/月（年付 $3.38）。差价不大，但 NVMe 在小文件读写和数据库响应上比 HDD 明显，能选 NVMe 就别省这 $0.26。

**只带 IPv6 的套餐更便宜，从 $1.60/月起。** 没有 IPv4 地址，绝大多数建站、远程登录、面板访问场景用不了。省下的钱换来一堆麻烦，不建议。

**“不限流量”是真的不限吗？**

套餐页没有标注大陆优化线路。对延迟敏感的话，先月付一个月，选好机房实测，再决定要不要年付。
